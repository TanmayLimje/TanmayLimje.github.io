# TanmayLimje.github.io

Personal portfolio website built with pure HTML, CSS, and JavaScript. Hosted on GitHub Pages.

## 🎨 Design

- **Style:** Dark minimalist theme inspired [Odysseus](https://github.com/pewdiepie-archdaemon/odysseus)
- **Colors:** Deep slate background with cyan (`#5fb6cc`) and coral (`#e06c75`) accents
- **Typography:** Inter, Space Grotesk, JetBrains Mono
- **Effects:** Perlin noise flow-field background, glassmorphism cards, scroll reveal animations

## 🚀 Features

- Responsive design (mobile + desktop)
- Animated flow-field canvas background
- Scroll-triggered reveal animations
- Sticky navigation with active section highlighting
- Glassmorphism card design
- Smooth scrolling anchor links

## 📁 Structure

```
.
├── index.html          # Main page
├── css/
│   └── style.css      # Styles
├── js/
│   └── main.js        # Interactions & flow field
└── README.md
```

## 🛠 Customization

1. **Personal info:** Edit `index.html` — replace placeholder text with your actual details
2. **Colors:** Modify CSS custom properties in `css/style.css` under `:root`
3. **Projects:** Update the project cards in `index.html` with your real repos
4. **Links:** Update social links in the hero and contact sections
